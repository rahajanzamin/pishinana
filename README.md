# 🎀 PISHINANA — فروشگاه کوچولوی خوشگل‌ها

فروشگاه اینترنتی کامل با **لاراول ۱۳ + Blade** — طراحی کاوهایی صورتی، راست‌چین (RTL)،
با صحنه‌های **سه‌بعدی تعاملی** (Three.js) در هیرو و بخش شخصی‌سازی محصول.

---

## ✨ امکانات

### بخش فروشگاه 🛍️
- صفحه‌ی اصلی با صحنه‌ی سه‌بعدی تعاملی (عروسک بامزه — با موس بچرخونش!)
- فروشگاه با **فیلتر** (دسته‌بندی، رنگ، قیمت، مجموعه)، **جست‌وجو** و **مرتب‌سازی**
- صفحه‌ی محصول با گالری رنگ، موجودی و افزودن به سبد
- **سبد خرید** (برای مهمان هم کار می‌کند) + **تسویه‌حساب**
- **پرداخت زرین‌پال** (با حالت شبیه‌سازی‌شده تا کلید بگذاری)

### کاربران 👥
- ثبت‌نام / ورود / خروج
- پروفایل + ویرایش اطلاعات
- **سفارش‌های من** با پیگیری وضعیت (نمودار مراحل)
- **علاقه‌مندی‌ها** 💖
- **طراحی‌های اختصاصی من**

### طراحی اختصاصی 🎨 (شخصی‌ساز سه‌بعدی!)
- انتخاب نوع محصول (عروسک، کیف، ماگ، ...)
- **پیش‌نمایش زنده‌ی سه‌بعدی** — با تغییر رنگ و نوشته، مدل فوراً عوض می‌شود
- ثبت درخواست با تصویر الهام‌بخش

### پنل مدیریت 🛠️ (`/admin`)
- داشبورد با آمار (درآمد، سفارش‌ها، کاربران، پیام‌ها)
- مدیریت **محصولات** (CRUD کامل + آپلود تصویر + رنگ‌ها)
- مدیریت **دسته‌بندی‌ها** و **مجموعه‌ها**
- مدیریت **سفارش‌ها** (تغییر وضعیت)
- بررسی **طراحی‌های سفارشی**
- **پیام‌ها و ایده‌ها**

## 🚀 اجرا روی کامپیوتر

### پیش‌نیاز
- PHP 8.2+ (با اکستنشن‌های sqlite3, mbstring, xml, curl, zip, gd, intl, bcmath)
- Composer

### مراحل اجرا

```bash
cd pishinana

# ۱) وابستگی‌ها
composer install

# ۲) تنظیمات محیط (اگر .env نیست)
cp .env.example .env
php artisan key:generate

# ۳) دیتابیس (SQLite — بدون نیاز به نصب سرور دیتابیس)
touch database/database.sqlite
php artisan migrate --seed

# ۴) لینک تصاویر آپلودی
php artisan storage:link

# ۵) اجرا!
php artisan serve
```

مرورگر: `http://localhost:8000`

## 💳 فعال‌سازی درگاه زرین‌پال

فعلاً چون کلید درگاه خالی است، **درگاه شبیه‌سازی‌شده** نمایش داده می‌شود
(پرداخت آزمایشی موفق/ناموفق). برای پرداخت واقعی در `.env`:

```env
ZARINPAL_MERCHANT_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
ZARINPAL_SANDBOX=false
```

- `ZARINPAL_SANDBOX=true` → محیط آزمایشی زرین‌پال
- `ZARINPAL_SANDBOX=false` → محیط واقعی (پرداخت پول واقعی)

## ✏️ راهنمای سریع تغییرات

| چی؟ | کجا؟ |
|---|---|
| متن‌های سایت | `resources/views/*.blade.php` |
| رنگ‌های اصلی (صورتی‌ها) | `public/css/app.css` بخش `:root` |
| محصولات و دسته‌ها | پنل ادمین `/admin` یا `database/seeders/DatabaseSeeder.php` |
| سرعت چرخش سه‌بعدی | `public/js/kawaii-scene.js` → `animate()` |
| مدل‌های سه‌بعدی | `public/js/kawaii-scene.js` → `buildProduct()` |
| تنظیمات درگاه | `.env` → `ZARINPAL_*` |

## 🔮 قدم‌های بعدی

1. **تصاویر واقعی محصولات** — عکس‌های `public/images/` را با عکس‌های واقعی عوض کن
2. **مدل‌های GLB سه‌بعدی** — برای شخصی‌ساز، مدل‌های حرفه‌ای‌تر با `GLTFLoader`
3. **ایمیل و پیامک** — اطلاع‌رسانی سفارش‌ها (Laravel Notifications)
4. **استقرار روی اینترنت** — اشتراک‌گذاری روی هاست لاراول یا VPS
